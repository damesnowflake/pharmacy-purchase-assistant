# 약국 사입 추천 시스템

직원이 판매·입고 자료를 등록하면 시스템이 사입 검토안을 만들고, 관리자가 확인해 직접 발주하는 웹 서비스입니다. 현재는 문서 단계이며 서비스 기능은 아직 구현되지 않았습니다.

**현재 개발 기준:** [사입 추천 시스템 개발 작업지시서](docs/사입추천시스템_개발작업지시서.md)

## 업무 흐름

1. 직원이 Windows 11의 CatPOS Cloud(팜페이) PC에서 판매내역을 하루 한 번 내보내 업로드합니다. 시스템은 품목별·일자별 판매수량으로 집계합니다.
2. 직원이 iPhone에서 종이 입고장을 촬영·OCR하고 품목과 실제 입고 수량만 확인해 등록합니다. 사진은 서버에 보관하지 않습니다.
3. 시스템이 최근 180일 판매 추세, 재고 참고값, 공휴일을 제외한 2영업일 도착일을 이용해 사입 검토안을 만듭니다.
4. 관리자가 Windows 또는 macOS에서 추천을 검토·수정하고, 실제 발주 후 완료 표시합니다.
5. 이후 입고를 등록하면 품목별 발주량 대비 입고량을 확인하고 진행 중 목록을 갱신합니다.

사전 발급 계정만 로그인할 수 있으며 계정은 지정된 마스터 계정 보유자 또는 백엔드 개발자가 직접 발급합니다. 서비스 사용 권한은 관리자와 직원 두 종류이고, 관리자가 발주 담당자를 겸합니다. 다섯 명 안팎의 사용자가 같은 최신 자료를 볼 수 있도록 웹 표준을 따르는 반응형 서비스로 개발합니다.
